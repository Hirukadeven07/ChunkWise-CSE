# SLM Benchmarking

Builds a question-answering benchmark from a company annual report and uses it to evaluate small language models (Granite, Gemma and Qwen) running locally through Ollama. Question generation is adapted from YourBench and evaluation from LightEval. Put the report in `data/annual_report/` and run `run.ps1` (Windows) or `run.sh` (Linux/macOS).
